## Aplikasi Manajemen Waktu Berbasis Pomodoro

Aplikasi mobile berbasis Flutter yang membantu pengguna mengatur waktu belajar dan kegiatan menggunakan metode Pomodoro dengan dukungan jadwal kegiatan dan statistik produktivitas.

## 🎯 Tujuan

- Membantu pengguna fokus dan konsisten belajar
- Mengelola kegiatan harian, mingguan, atau satu kali
- Menyediakan statistik fokus sebagai evaluasi produktivitas

## 👤 Target Pengguna

Mahasiswa, remaja dan dewasa

## 🛠️ Teknologi

- Flutter (Mobile App)
- REST API (HTTP)
- State Management (Provider / Riverpod)
- Database (Server-side)

## ✨ Fitur Utama

- Login pengguna
- Manajemen task & jadwal kegiatan
- Pomodoro multi-cycle (short & long break)
- Progress cycle per task
- Statistik fokus (harian, mingguan, bulanan)
- Profil pengguna & status “sedang belajar”

## 📱 Platform

- Android (Mobile)

## 📌 Catatan

Proyek ini dikembangkan sebagai **Tugas Besar Mata Kuliah Pemrograman Mobile**.
